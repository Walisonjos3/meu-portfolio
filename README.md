# 🚀 Portfólio Evolutivo | Front-End Journey

Bem-vindo(a) ao meu repositório de portfólio! 👋

Este repositório tem como objetivo documentar a minha evolução prática no desenvolvimento Front-End. Aqui registro meus projetos, desafios de código e a aplicação contínua de novas tecnologias e boas práticas de desenvolvimento web.

---

## 🛠️ Tecnologias e Conceitos Aplicados

- **HTML5:** Estrutura semântica, acessibilidade e organização de tags.
- **CSS3:** Estilização, reset de CSS, herança, especificidade e variáveis.
- **Flexbox:** Alinhamento de layouts, responsividade, `display: flex`, `flex-direction`, `gap` e distribuição de espaço.
- **Git & GitHub:** Versionamento de código, mensagens de commit semânticas e documentação de progresso.

*(À medida que for avançando nos estudos, adicionarei JavaScript, CSS Grid, React, etc.)*

---

## 📌 Histórico do Projeto e Marcos (Milestones)

- [x] **Fase 1:** Estrutura básica em HTML5 e estilização simples.
- [x] **Fase 2:** Implementação do mini portfólio usando **HTML Semântico** e **Flexbox** para layouts modernos.
- [ ] **Fase 3:** Responsividade e Media Queries (Mobile First / Layouts adaptáveis).
- [ ] **Fase 4:** Interatividade e lógica com JavaScript.
